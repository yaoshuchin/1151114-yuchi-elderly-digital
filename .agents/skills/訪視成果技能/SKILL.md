# 訪視成果技能 (Inspection Results Showcase Skill)

本技能彙整自「教育部南投縣樂齡學習數位示範體驗場域（魚池）」訪視輔導展示系統的實戰開發技術，為政府督導評鑑、教育訪視、社造結案與場域成果展示提供現代化單頁系統（SPA）的標準建構流程。

---

## 🏛️ 一、標準「4+1」模組架構

```
訪視成果展示系統
├── 🏛️ 場域中心：實體地圖 (Google Maps)、街景導引、外展拓點網絡、在地宣導影片播放清單與新聞報導
├── 🌟 A. 成果網頁：KPI 核心數據儀表板、四大維度成果（空間設備、人力制度、課程教學、推廣策略）、簡報直達鈕
├── 🎯 B. 問答模式：委員常見提問（FAQ）、重點標記、對應簡報頁碼一鍵直達
├── 📽️ C. 簡報模式：25 頁高解析投影片、視窗最適化自適應、全螢幕正下方畫筆浮動工具列（換頁、畫筆、白板、橡皮擦、復原、退出）
└── 📱 QR 分享專區：官方完整網址條碼 + TinyURL 縮網址條碼、一鍵複製剪貼簿、點圖燈箱放大檢視（Lightbox）
```

---

## 🎨 二、無障礙與視覺調適規範

1. **頂部右上角工具列排版**：
   - 頂部第一行左側為品牌與場域全銜，**右上方空白處**靠齊配置「字體縮放」、「布景切換」與「水晶音樂播放器」。
   - 頂部第二行獨立展開五大核心分頁，版面整齊、大方、不壅塞。
2. **根字級全局連動縮放 (Root Font-Size Scaling)**：
   - 透過修改 `html[data-font]` 根字級，全站所有使用 `rem` 的排版元素等比縮放：
     - **中（16px）**：標準公務檢視。
     - **大（19px）**：長者閱讀推薦。
     - **特大（23px）**：高齡輔助與遠距投影展示。
3. **四色情境主題切換**：
   - 透過 `body[data-theme]` 與 CSS Custom Properties 即時切換：
     - **🌿 茶園綠 (Green)**：融入魚池在地生態與創生氣息。
     - **🌊 科技藍 (Blue)**：象徵日月潭與智慧學習意象。
     - **☀️ 淺色系 (Light)**：明亮大方、高階報告質感。
     - **🌙 深色系 (Dark)**：夜間抗疲勞與投影防眩光。
4. **原生 Web Audio API 水晶音樂合成系統**：
   - 純 JavaScript 原生合成正弦波與泛音鐘音，零版權問題、無 MP3 載入延遲。
   - 內建 4 首不同調性水晶樂曲（清晨微風、山林漫步、陽光茶園、寧靜星空）與靜音控制。

## 📽️ 三、簡報白板與全螢幕正下方工具列

1. **全螢幕正下方懸浮工具列（Fullscreen Bottom Docked Toolbar）**：
   - 進入全螢幕時，工具列自動固定浮現在**螢幕正下方中央**。
   - 整合換頁控制（`◀ 上一頁`、`1 / 25`、`下一頁 ▶`）、`✏️ 畫筆開關`、全套繪圖標記工具與`✖ 退出`。
2. **HTML5 Canvas 螢幕白板手繪引擎**：
   - **筆刷**：自由畫筆（Pen）、半透明標記螢光筆（Highlighter）。
   - **幾何圖形**：直線（Line）、指向箭頭（Arrow）、矩形（Rect）、圓形（Circle）。
   - **調色盤**：紅、黃、綠、藍、白 5 種常用標記色與 3 段粗細。
   - **操作輔助**：局部橡皮擦、復原上一筆（Undo Stack）、一鍵清空畫布。
3. **視窗最適化切換 (Fit Viewport)**：
   - 提供「📐 視窗最適」模式，將簡報高度約束於瀏覽器視窗內，免滾動即可完整呈現。

---

## 📱 四、QR 條碼與點圖放大燈箱

1. **二維條碼點圖放大燈箱 (Lightbox Modal)**：
   - 條碼框附帶「🔍 點擊放大條碼」提示與立體浮動手勢。
   - 點擊後彈出 330×330px 高解析放大條碼與深色毛玻璃背景，利於現場遠距投影螢幕掃描。
   - 支援右上關閉鈕、按 `Esc` 鍵或點選黑色背景退出。
2. **雙軌網址分享與複製**：
   - 同時提供官方完整公開網址與極簡縮網址（TinyURL），並配置一鍵複製剪貼簿按鈕與綠色成功氣泡。

---

## 🛠️ 五、自動化工具鏈 (scripts/)
1. **`extract_presentation_assets.py`**：自動解包 PPTX 提取實境活動照片至 `doc_media/`，並批次匯出 1080P PNG 投影片至 `slides_img/`。
2. **`generate_qrcodes_api.py`**：雙軌條碼生成器，優先使用本機 `qrcode` 模組，無模組時自動切換 Web API 產製 500x500 高清條碼。
3. **`crystal_synth_engine.js`**：輕量化 Web Audio 水晶音效合成器模組。
