# 訪視成果展示系統架構詳細規格書

## 1. 系統定位
訪視成果展示系統（Inspection Results Showcase System）專為各級政府督導評鑑、教育場域訪視、社造計畫結案、樂齡場域輔導而設計。其主要訴求為：
- **零門檻存取**：免登入、無伺服器後端負擔（純前端 HTML5 / CSS3 / ES6）。
- **長者友善**：大按鈕、大字級、高對比、不刺眼色彩。
- **評鑑專注**：以指標為導向，任何提問與面向皆可 1 秒連動簡報對應頁。

---

## 2. 模組職責拆解

| 模組分頁 | 識別 ID | 核心職責 | 互動亮點 |
| :--- | :--- | :--- | :--- |
| **🏛️ 場域中心** | `#modeCenter` | 空間場域、實體地圖、拓點外展、新聞影音 | Google Maps、拓點標籤網格、在地影音播放清單 |
| **🌟 A. 成果網頁** | `#modeA` | 敘事型圖文成果、四大維度指標、量化達成率 | 成果數據儀表盤、維度卡片跳轉按鈕、活動照片輪播 |
| **🎯 B. 問答模式** | `#modeB` | 委員常見提問（FAQ）、法規與執行難題釋疑 | 手風琴平滑折疊展開、提問標籤、對應簡報頁直達按鈕 |
| **📽️ C. 簡報模式** | `#modeC` | 完整 25 頁高解析投影片巡迴展示、現場答詢 | 全螢幕/視窗最適、縮圖軌道、HTML5 Canvas 畫筆標記工具 |
| **📱 QR 分享專區** | `#modeQR` | 現場手機快速接入、委員帶走成果、縮網址宣傳 | 一鍵剪貼簿複製、完整/縮網址條碼、點圖燈箱放大檢視 |

## 3. 狀態管理與路由設計
- **URL Hash 路由**：監聽 `window.location.hash`（`#modeCenter`、`#modeA`、`#modeB`、`#modeC`、`#modeQR`），保證上一頁/下一頁可回溯，且可將特定分頁網址直接分享。
- **深色/布景主題儲存**：`localStorage.getItem('app-theme')`，支援 `light`, `dark`, `green`, `blue`。
- **字體偏好儲存**：`localStorage.getItem('app-font-size')`，支援 `medium`, `large`, `xlarge`。
- **背景音樂狀態**：`localStorage.getItem('app-music-muted')`，支援記住長輩的靜音偏好。

## 4. 關鍵組件實作要領
### 4.1 維度卡片與簡報雙向跳轉
在 A 成果網頁或 B 問答模式中，加入帶有 `data-slide="N"` 的按鈕：
```html
<button class="jump-slide-btn" data-slide="12">查看幫手簡報 P.12 ➔</button>
```
點擊時：
1. 切換模式至 `#modeC`。
2. 呼叫 `renderSlide(N)` 更新投影片圖檔與狀態。
3. 自動滾動縮圖軌道至該頁。
