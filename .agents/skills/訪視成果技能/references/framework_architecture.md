# 通用成果展示系統架構詳細規格書 (Framework Architecture Spec)

## 1. 系統定位與通用性原則
本通用成果展示系統專為各類政府專案、評鑑訪視、結案成果、年終展示而設計。無論任何主題，皆依循以下通用原則：
- **純前端零伺服器 (Serverless Static)**：無後端依賴、無資料庫維護成本，透過 GitHub Pages 等靜態託管平臺即開即用。
- **無障礙友善 (Accessibility First)**：兼顧年長者、一般訪客與專業審查委員之閱讀需求，字級與對比度全平臺等比自適應。
- **指標直達 (Smart Jump)**：任何綱要、文字維度或問答考題皆可 1 秒無縫切換至簡報對應頁。

---

## 2. 通用「4+1」模組職責標準

| 模組分頁 | 識別 ID | 核心職責 | 互動亮點 |
| :--- | :--- | :--- | :--- |
| **🏛️ 場域/專案中心** | `#modeCenter` | 實體定位、組織使命、拓點網絡、宣導影音 | 響應式 Google Maps、據點網格徽章、YouTube 播放清單與新聞卡片 |
| **🌟 A. 成果網頁** | `#modeA` | 敘事型成果展現、KPI 數據儀表板、多面向卡片 | 量化指標卡、各面向配備「查看簡報 P.X ➔」直達鈕、實體照片輪播 |
| **🎯 B. 問答模式** | `#modeB` | 委員常見提問（FAQ）、執行痛點與法規釋疑 | 手風琴平滑折疊開合、關鍵字綠底標記、對應簡報頁碼直達鈕 |
| **📽️ C. 簡報模式** | `#modeC` | 完整投影片巡演、白板手繪、全螢幕放映 | 視窗最適/全螢幕、正下方微型畫筆工具列、隨身備忘講稿、縮圖軌道 |
| **📱 QR 分享專區** | `#modeQR` | 現場手機快速接入、委員帶走成果、縮網址宣傳 | 完整網址條碼 + TinyURL 縮網址條碼、一鍵剪貼簿複製、點圖高解析燈箱放大 |

## 3. 階層式頂部導覽列佈局 (Top-Right 工具列)
頂部導覽列採雙層架構：
1. **頂部第一行**：
   - 左側：專案識別 Logo 與計畫全銜。
   - **網頁右上方空白處 (`margin-left: auto`)**：依序排列「字體縮放（中/大/特大）」、「布景主題（淺/深/主色一/主色二）」與「Web Audio 背景音樂播放器」。
2. **頂部第二行**：五大核心功能分頁（`#modeCenter`、`#modeA`、`#modeB`、`#modeC`、`#modeQR`）獨立橫向展開，空間充裕、不擁擠。

---

## 4. 狀態管理與路由設計
- **URL Hash 路由**：監聽 `window.location.hash`（`#modeCenter`、`#modeA`、`#modeB`、`#modeC`、`#modeQR`），保證上一頁/下一頁可回溯，且可將特定分頁網址直接分享。
- **深色/布景主題儲存**：`localStorage.getItem('app-theme')`，支援 `light`, `dark`, `green`, `blue` 等。
- **字體偏好儲存**：`localStorage.getItem('app-font-size')`，支援 `md`, `lg`, `xl`。
- **背景音樂狀態**：`localStorage.getItem('app-music-muted')`，支援記住訪客靜音偏好。

---

## 5. 跨分頁智慧雙向連動 (Smart Jump)
在 A 成果網頁或 B 問答模式中，為按鈕添加 `data-slide="頁碼"`：
```html
<button class="jump-slide-btn" data-slide="12">查看簡報 P.12 ➔</button>
```
點擊時：
1. 切換模式至 `#modeC`（簡報模式）。
2. 呼叫 `renderSlide(12)` 更新投影片影像與講稿。
3. 自動滾動底部縮圖軌道至該頁。
